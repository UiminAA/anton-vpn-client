Anton VPN - third-party software and corresponding sources
========================================================

The installer includes an UNMODIFIED official v2rayN Windows x64 desktop
release archive. It contains no account, subscription, VPN server credential,
or data copied from an existing user's installation. The installer creates
configuration separately after the user supplies a personal connection link.
