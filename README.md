# Мой VPN

Установщик для Windows 10/11 x64. Получатель скачивает один EXE, вставляет **свою** ссылку `vless://` от владельца VPN и устанавливает приложение. При установке проверяется подключение по этой ссылке. Установщик не содержит ключей пользователей или доступа к серверной панели.

**[Скачать установщик](https://github.com/UiminAA/anton-vpn-client/releases/latest/download/AntonVPN-Setup-1.0.0.exe)** · [Релиз и контрольная сумма](https://github.com/UiminAA/anton-vpn-client/releases/tag/v1.0.0)

## Как установить

1. Скачай файл `AntonVPN-Setup-1.0.0.exe` из последнего релиза этого репозитория.
2. Запусти его в той учётной записи Windows, где будешь пользоваться VPN. Подтверди запрос прав администратора. Нужна собственная учётная запись с правами администратора; ввод данных другой учётной записи не поддерживается.
3. Вставь личную ссылку, которую выдал Антон. При необходимости отключи «Включать VPN при входе в Windows».
4. Нажми «Установить VPN», дождись проверки и нажми «Включить VPN».

При первом скачивании Windows может показать SmartScreen: у файла нет коммерческой цифровой подписи. Проверяй источник скачивания и при необходимости сравни SHA-256 с `SHA256SUMS.txt` в том же релизе.

Для запуска используй ярлык **«Мой VPN»** на рабочем столе. Для замены личной ссылки — **«Настроить VPN»** в меню «Пуск». Перед заменой ссылки закрой клиент через значок возле часов. Для отключения VPN выбери «Выход» в меню значка v2rayN возле часов. Удаление доступно в «Параметры → Приложения → Мой VPN».

## Какие сайты идут через VPN

- ChatGPT / OpenAI, Claude / Anthropic, YouTube, Instagram.
- Telegram Desktop, в том числе по имени процесса `Telegram.exe`.
- Приложения ChatGPT по имени процесса.

Google Search, Gmail, Drive, Docs и остальные адреса идут напрямую. Полный перечень правил — `assets/split-routing.json`.

Перед установкой или первым запуском закрой другие VPN-клиенты. Приложение использует TUN, работает через задачу Windows с правами администратора и не меняет настройки других VPN. Системный HTTP-прокси не настраивается. Автозапуск действует для пользователя, который установил программу.

Личная ссылка сохраняется только в профиле установленного клиента внутри `%LOCALAPPDATA%\Programs\AntonVPN`. Каталог защищён правами владельца, Administrators и SYSTEM. Не отправляй этот каталог другим людям. Для каждого пользователя выдавай отдельную ссылку в панели управления VPN.

## Состав

- Мастер и программа запуска: C#, .NET Framework 4.8, Windows Forms.
- Официальный автономный v2rayN 7.25.4 Windows x64.
- Ядро sing-box 1.14.0 из этого архива.
- Первоначальная настройка SQLite-профиля, выборочных маршрутов и DNS.
- Проверка ссылки через отдельный локальный прокси без включения TUN.
- Установка с откатом при ошибке, ярлыки, автозапуск и удаление.

Состав и контрольные суммы официальных компонентов: `assets/upstream.json`. Лицензии и ссылки на соответствующие исходники: `THIRD-PARTY.txt`, `licenses/`.

## Сборка и проверки

На Windows x64 с .NET Framework 4.8:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\Fetch-Client.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Build.ps1
```

Скрипт загрузки получает только закреплённый официальный архив и проверяет SHA-256. Сборка использует штатный компилятор Windows, не требует Visual Studio и создаёт `dist/AntonVPN-Setup-1.0.0.exe`. В `dist/SHA256SUMS.txt` записывается контрольная сумма готового файла. Тесты распаковывают официальный пакет в `.qa/payload`, проверяют версии, разбор ссылок, SQLite и маршруты без изменения сети, задач и установленного VPN.

Для локального просмотра формы без установки и запроса прав:

```powershell
.\.qa\AntonVPN.exe --render-preview .qa\installer-preview.png
```

Сборка и локальные проверки не заменяют проверку полного цикла на отдельном компьютере: установка с личной ссылкой, запуск TUN, маршруты Google/VPN, перезагрузка, обновление и удаление.

Проверено 18.10.2026: сборка установщика и программы запуска; состав и версии официального пакета; 85 проверок разбора ссылок, SQLite, настроек и маршрутов; чтение Windows Task Scheduler и проверка команды задачи без её регистрации; внешний вид формы. Отдельная проверка ядром из пакета прошла реальное подключение к серверу через локальный прокси. Действующий VPN компьютера не переключался. Полный цикл UAC/установка/TUN/перезагрузка/удаление на отдельном компьютере пока не проверен.
